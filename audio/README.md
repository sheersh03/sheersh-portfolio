# Soundtrack & stings

All optional — the site works with **zero** audio files present (each plays
only when found, and the `Sound` toggle still tracks state regardless).

⚠️ Do **not** use the actual Marvel Studios fanfare or any official audio — it
is copyrighted. Use CC0 / licensed-for-use cinematic clips, or commission
original ones.

Expected files (drop in royalty-free / original `.mp3`s):

| File | Plays when |
|------|------------|
| `intro-sting.mp3` | ambient loop, toggled by the `Sound` control |
| `ironman.mp3` | Iron Man hero powers up |
| `spiderman.mp3` | Spider-Man hero powers up |
| `hulk.mp3` | Hulk hero powers up |
| `thor.mp3` | Thor hero powers up |
| `loki.mp3` | Loki hero powers up |
| `assemble.mp3` | Konami-code easter egg |
